# Content rating (IARC) questionnaire — the answers

Play Console → **Policy → App content → Content rating**. The questionnaire is short
for a productivity app; every answer here is **No**.

**Category:** Utility, Productivity, Communication or Other
(pick **Utility, Productivity...** — not Social, not Entertainment).

| Question | Answer |
| --- | --- |
| Violence — realistic, cartoon, or otherwise | No |
| Sexuality or nudity | No |
| Language — profanity or crude humour | No |
| Controlled substances — drugs, alcohol, tobacco | No |
| Gambling, simulated gambling, or in-game currency | No |
| Horror or fear-inducing content | No |
| Miscellaneous — content that could be disturbing | No |
| **Does the app allow users to interact or exchange content?** | **No** — Milestone has no accounts, no network access and no user-to-user features of any kind |
| Does the app share the user's location with other users? | No |
| Does the app allow users to purchase digital goods? | No |
| Does the app contain user-generated content that is shared? | No — the user writes goals and reflections, but they are visible only on their own device |
| Does the app display ads? | No |

**Expected outcome:** Everyone (ESRB) / PEGI 3 / rated for all ages in every region.

One thing to be careful of: the "allow users to interact" question is about the app
enabling communication between people. Exporting a backup that the user then chooses
to email to themselves is not an in-app interaction feature; answer **No**.
